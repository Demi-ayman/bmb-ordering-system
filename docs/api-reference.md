# API Reference

## Conventions

- Base path: `/api/v1`
- Media type: `application/json`
- Authentication: JWT bearer token
- Timestamps: UTC ISO 8601
- Money: JSON decimal values, stored as `decimal(18,2)`

Protected requests use:

```http
Authorization: Bearer <access-token>
```

## Roles

| Role | Access |
|---|---|
| Anonymous | Registration and login |
| Customer | Own order creation, retrieval, listing, and deletion |
| Administrator | Customer role plus system-wide and customer-management queries |

## Endpoint summary

| Method | Route | Access | Success |
|---|---|---|---|
| `POST` | `/api/v1/auth/register` | Anonymous | `201 Created` |
| `POST` | `/api/v1/auth/login` | Anonymous | `200 OK` |
| `POST` | `/api/v1/orders` | Customer | `201 Created` |
| `GET` | `/api/v1/orders` | Customer | `200 OK` |
| `GET` | `/api/v1/orders/all` | Administrator | `200 OK` |
| `GET` | `/api/v1/orders/{orderId}` | Customer owner | `200 OK` |
| `DELETE` | `/api/v1/orders/{orderId}` | Customer owner | `200 OK` |
| `GET` | `/api/v1/admin/customers` | Administrator | `200 OK` |
| `GET` | `/api/v1/admin/customers/{customerId}/orders` | Administrator | `200 OK` |

## Authentication

### Register customer

```http
POST /api/v1/auth/register
```

```json
{
  "fullName": "Demiana Ayman",
  "email": "demiana@example.com",
  "password": "StrongPass1",
  "passwordConfirmation": "StrongPass1"
}
```

Rules:

- Full name is required and limited to 150 characters.
- Email is required, valid, unique case-insensitively, and limited to 256 characters.
- Password length is 8–100 characters and requires uppercase, lowercase, and numeric characters.
- Confirmation must match exactly.

Example `201 Created` response:

```json
{
  "customerId": "c209a943-4161-45b4-97b8-0a095c35670c",
  "fullName": "Demiana Ayman",
  "email": "demiana@example.com",
  "createdAtUtc": "2026-08-20T09:00:00Z"
}
```

Returns `409 Conflict` when the normalized email already exists.

### Login

```http
POST /api/v1/auth/login
```

```json
{
  "email": "demiana@example.com",
  "password": "StrongPass1"
}
```

Example `200 OK` response:

```json
{
  "customerId": "c209a943-4161-45b4-97b8-0a095c35670c",
  "fullName": "Demiana Ayman",
  "email": "demiana@example.com",
  "accessToken": "<jwt>",
  "accessTokenExpiresAtUtc": "2026-08-20T09:30:00Z",
  "bannedUntilUtc": null
}
```

Returns `401 Unauthorized` for invalid credentials.

## Customer orders

### Create order

```http
POST /api/v1/orders
```

```json
{
  "items": [
    {
      "productName": "Keyboard",
      "quantity": 2,
      "unitPrice": 750.50
    },
    {
      "productName": "Mouse",
      "quantity": 1,
      "unitPrice": 250.00
    }
  ]
}
```

Rules:

- An order contains 1–100 items.
- Product name is required and limited to 200 characters.
- Quantity must be greater than zero.
- Unit price cannot be negative or have more than two decimal places.
- Totals and order numbers are generated by the server.

Example `201 Created` response:

```json
{
  "id": "ab9c68f4-8af6-4739-b561-88d742510bac",
  "customerId": "c209a943-4161-45b4-97b8-0a095c35670c",
  "orderNumber": "ORD-20260820090000-9BA7DCE6",
  "status": "Created",
  "totalAmount": 1751.00,
  "createdAtUtc": "2026-08-20T09:00:00Z",
  "deletedAtUtc": null,
  "items": [
    {
      "id": "29729777-1fd3-4bfa-b845-07a69355fbb7",
      "productName": "Keyboard",
      "quantity": 2,
      "unitPrice": 750.50,
      "lineTotal": 1501.00
    },
    {
      "id": "fc1450a2-28d1-417d-81ab-f77039c656b2",
      "productName": "Mouse",
      "quantity": 1,
      "unitPrice": 250.00,
      "lineTotal": 250.00
    }
  ]
}
```

Returns `403 Forbidden` while the customer is temporarily banned.

### List current customer's orders

```http
GET /api/v1/orders
```

Returns active orders owned by the authenticated customer. Soft-deleted orders are excluded.

### Retrieve owned order

```http
GET /api/v1/orders/{orderId}
```

Returns `404 Not Found` when the order does not exist, is deleted, or belongs to another customer.

### Delete owned order

```http
DELETE /api/v1/orders/{orderId}
```

Example `200 OK` response:

```json
{
  "orderId": "ab9c68f4-8af6-4739-b561-88d742510bac",
  "deletedAtUtc": "2026-08-20T09:10:00Z",
  "qualifiesForBanCount": true,
  "qualifyingDeletionCount": 3,
  "bannedUntilUtc": "2026-08-20T15:10:00Z"
}
```

The endpoint soft-deletes the order and records exactly one deletion event.

## Administrator operations

### List all orders

```http
GET /api/v1/orders/all
```

Returns all active and deleted orders across customers.

### List customers

```http
GET /api/v1/admin/customers
```

Example customer entry:

```json
{
  "id": "c209a943-4161-45b4-97b8-0a095c35670c",
  "fullName": "Demiana Ayman",
  "email": "demiana@example.com",
  "createdAtUtc": "2026-08-20T09:00:00Z",
  "bannedUntilUtc": null,
  "isOrderingBanned": false
}
```

### List a customer's order history

```http
GET /api/v1/admin/customers/{customerId}/orders
```

Returns active and deleted orders for the selected customer. Returns `404 Not Found` when the customer does not exist.

## Error responses

Errors use `application/problem+json`.

Example validation response:

```json
{
  "type": "https://httpstatuses.com/400",
  "title": "Validation failed",
  "status": 400,
  "instance": "/api/v1/orders",
  "errors": {
    "Items": [
      "An order must contain at least one item."
    ]
  },
  "traceId": "<request-trace-id>"
}
```

| Status | Meaning |
|---:|---|
| `400` | Validation or domain-rule violation |
| `401` | Missing/invalid token or invalid login credentials |
| `403` | Missing required role or temporary ordering ban |
| `404` | Resource absent or not owned by the caller |
| `409` | Duplicate email or conflicting operation |
| `500` | Safe generic response for an unexpected server error |
